## What it does

- A sphere, a plane and a donut, slowly rotating.
- A menu in the top-right corner switches between all the materials from the handout.
- The default material uses all the door textures (color, height, normal, metalness, roughness...).

## How to run

```bash
npm install
npm run dev
```

Then open the link it prints in your browser.
