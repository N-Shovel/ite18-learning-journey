# Activity 1.12 - How it was published

**Live site:** <https://pala-nimrod-threejs-go-live.vercel.app>

1. Installed Vercel in the project: `npm install vercel`
2. Added a `deploy` script to `package.json`: `"deploy": "vercel --prod"`
3. Ran `npm run deploy`, logged in to Vercel, and answered the setup questions
   (new project, code in `./`, output folder `dist`).
4. Vercel built the project and gave the live link above.

To publish an update, run `npm run deploy` again.
