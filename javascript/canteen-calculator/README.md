## How to Run

1. Open the project folder.
2. Double-click `index.html`.
3. The file will open in your web browser.
4. Follow the prompts to enter the customer information and quantities.

## How to Open Developer Console Tools

1. With the webpage open, press `F12` on your keyboard.
2. Select the **Console** tab.
3. View the calculator's output and messages there.
4. Refresh the page to run the calculator again.
