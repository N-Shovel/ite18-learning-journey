## What it does

- Images (textures) are loaded and placed on a cube.
- The final result is a pixelated Minecraft-style block.
- The other texture steps from the handout are kept in the code as comments.

## How to run

```bash
npm install
npm run dev
```

Then open the link it prints in your browser.
