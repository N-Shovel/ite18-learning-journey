## What it does

- A red cube in an 800x600 canvas.
- You can drag with the mouse to rotate the camera around the cube (OrbitControls).
- The camera slows down smoothly when you let go (damping).

## How to run

```bash
npm install
npm run dev
```

Then open the link it prints in your browser.
